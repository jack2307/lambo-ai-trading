Q1 - THE TWO LEGS AS FUNCTIONS OF reward_risk (rr).  NO GATE ON THIS AXIS.
============================================================================================================
A1..A4 of the registration: every trade closes at exactly -1R or +rr*R, one R per
trade, costs already inside the payoffs, PF = sum(+R)/|sum(-R)|.  Let w = win rate.

  expectancy  E  = w*rr - (1-w)*1 = w(1+rr) - 1
    E >= +0.050R   <=>   w >= (1 + 0.050) / (1 + rr)        = w_E(rr)

  profit factor  PF = w*rr / ((1-w)*1)
    PF >= 1.200     <=>   w >= 1.200 / (rr + 1.200)         = w_PF(rr)

  the leg that BINDS is the one with the HIGHER threshold win rate:
    D(rr) = w_PF - w_E = [1.20(1+rr) - 1.05(rr+1.20)] / ((rr+1.20)(1+rr))
                       = 0.15 * (rr - 0.400) / ((rr + 1.200)(rr + 1))

  ONE root, at rr = 0.400, and the denominator is positive for every rr > 0, so the
  sign of D changes exactly once:
    rr <  0.400  ->  D < 0  ->  the EXPECTANCY leg binds, PF is redundant
    rr =  0.400  ->  D = 0  ->  both legs demand w = 75.0%
    rr >  0.400  ->  D > 0  ->  the PF leg binds, EXPECTANCY is redundant

  derivatives (so a later reader can re-derive the root without this script):
    dw_PF/drr = -1.20 / (rr + 1.20)^2        dw_E/drr = -1.05 / (1 + rr)^2
    dD/drr  = 1.05/(1+rr)^2 - 1.20/(rr+1.2)^2 ;  at rr = 0.400 it is +0.0670 of win
    rate per unit rr, so +0.1 of rr above the root widens the gap by ~0.67 pp.

The derivation is missing a term, and here it is:

  drop A1 entirely and keep only A2 (one R per trade) and A4.  Write
  Lbar = |sum(-R)| / n, the GROSS LOSS PER TRADE in R, averaged over ALL n trades.
  Then, with no assumption whatever about how a trade exits:

        E  =  Lbar * (PF - 1)                 <- exact, always

  so    E >= +0.050R   <=>   PF - 1 >= 0.050 / Lbar
        PF >= 1.200    <=>   PF - 1 >= 0.200

  THE EXPECTANCY LEG IS REDUNDANT IF AND ONLY IF   Lbar >= 0.250 R.
  rr never appears.  It entered Q1 only through A1, which pins Lbar = (1-w); at the
  PF threshold that is Lbar = rr/(rr+1.2), and Lbar >= 0.250 <=> rr >= 0.400 - the
  SAME root.  So Q1 was a special case: correct, but blind to the only term that
  matters here, which is HOW BIG THE LOSSES ARE, not how far away the targets are.
